# 팀 프로젝트 업무 관리 시스템

## 프로젝트 소개
팀 프로젝트의 업무 분배, 진행 상황, 일정 및 마감일을 효율적으로 관리하기 위한 프로그램입니다.
팀원 간 업무 인수인계와 자동 알림 기능을 제공하며, AI 챗봇을 통해 프로젝트 진행에 필요한 정보를 지원합니다.

## 주요 기능

### 1) 프로젝트 및 업무 관리
- 프로젝트 등록 및 전체 마감일 설정
- 팀원 등록 및 역할 지정
- 업무 분배 및 개별 마감일 설정
- 팀원별 및 팀 전체 진행률 확인

### 2) 업무 인수인계 시스템
- 팀원 부재 시 다른 팀원에게 업무 인수인계 요청
- 인수인계 승인 및 거절
- 기존 업무 진행률과 자료 유지
- 기존 담당자 복귀 시 업무 재인수인계

### 3) 팀원별 주간 일정 관리
- 요일별 개인 일정 및 참여 불가 시간 등록
- 팀원별 주간 일정 조회
- 팀 전체 일정 통합 확인
- 공동 회의 가능 시간 확인

### 4) 마감일 PUSH 알림
- 마감일이 임박한 미완료 업무 자동 감지
- 담당 팀원에게 알림 제공
- 알림 중복 방지 및 발송 이력 관리
- 알림 클릭 시 해당 업무 화면으로 이동

※ 알림은 프로그램 실행 중에만 제공하며 모바일 PUSH 알림은 지원하지 않습니다.

### 5) 학교 API 연동 AI 챗봇
- 학교 API를 활용한 학교 관련 정보 제공
- AI 챗봇을 통한 사용자 질문 응답
- 학교 관련 정보 검색 및 안내 지원
